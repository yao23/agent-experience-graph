# Stage A recruitment authorization

This package is an activation proposal for candidate discovery and personalized
outreach only. It becomes effective only after the pull request containing the
root `approval-record.json` is separately reviewed and merged into `main`.
Draft or ready-but-unmerged state grants no authority.

If activated, it permits at most ten invite-ready pseudonymous candidate records,
ten individually reviewed personalized initial invitations, one follow-up per
candidate, and three voluntary unpaid Stage A enrollments. Use the already
reviewed participant-facing templates in `../templates/`; do not publish or send
those templates verbatim without individual review.

It does not authorize task execution, AEG queries on participant tasks, model-
assisted diagnosis or repair, private-repository access, source-code or raw-log
retention, external-project writes, payments, publication, experience promotion,
verified-library changes, Stage B, or any Scheduled Task.

The shortlist and outreach files are empty schemas/templates, not participant
records. Populated operational records must remain in an access-controlled store
and must never be committed to this public repository.
