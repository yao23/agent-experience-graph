# DRAFT — DO NOT DISTRIBUTE: post-task feedback

Use the pseudonymous task ID only.

1. Did the frozen objective oracle pass? (`yes`, `no`, `not executed`)
2. Which retrieval result occurred? (`relevant recommendation`, `correct
   abstention`, `irrelevant retrieval`, `misleading retrieval`)
3. Did AEG change a diagnosis, command, test, or avoided path? Describe the
   exact evidence; answer `no evidence` if uncertain.
4. Could the repair have succeeded independently of AEG? Why?
5. How useful was AEG's recommendation or abstention? (`1` not useful to `5`
   very useful) Give one short reason.
6. Did AEG create confusion, wasted work, risk, or false confidence?
7. Was the onboarding and privacy boundary clear?
8. May the sanitized evidence continue to be retained? (`yes` or `withdraw`)
9. Publication consent is separate and is not requested by this form.

Latency and token changes may be recorded as secondary observations but cannot
alone justify a success rating.
