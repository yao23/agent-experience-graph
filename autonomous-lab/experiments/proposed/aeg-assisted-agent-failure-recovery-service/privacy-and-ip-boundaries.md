# Privacy, security, license, and IP boundaries

## Acceptable inputs for a future approved phase

- Public source with explicit provenance/license, or material the requester is
  authorized to provide and have analyzed.
- Minimal reproductions stripped of unrelated content.
- Sanitized aggregate evidence sufficient for the objective oracle.

## Prohibited inputs and actions

- Credentials, tokens, private keys, secrets, production access, or hidden
  network dependencies.
- Personal identifiers, private conversations, raw private logs, regulated
  data, or unnecessary telemetry.
- Employer/client-owned or proprietary material without documented authority.
- License-incompatible copying, undisclosed public patches, or unlicensed
  redistribution.
- External writes, uploads, publication, or contact without separate approval.

## Handling rule

Reject rather than retain unsuitable material. Never place raw conversations,
full logs, private paths, credentials, external source trees, or proprietary
material in AEG. Preserve only sanitized evidence, public provenance, hashes,
objective results, and limitations needed for review.

Phase 0 collects no information and uses only existing public repository
evidence within Batch 01 and corrected Batch 02 limitations.
