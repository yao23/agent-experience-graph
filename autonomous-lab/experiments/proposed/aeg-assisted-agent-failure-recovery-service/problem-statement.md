# Problem statement

Developers can lose substantial time when an agent or CI workflow repeats the
same failed approach, produces a plausible but unverified patch, or cannot
separate environmental noise from a real regression. Existing logs may be too
large, sensitive, or poorly structured for efficient diagnosis.

The proposed service would turn a qualified reproduction into a bounded,
evidence-backed diagnostic package. It would distinguish:

- ordinary agent diagnosis and implementation;
- Autonomous Lab orchestration and evidence controls;
- AEG recommendation or abstention;
- objectively verified repair evidence;
- external maintainer or customer acceptance; and
- commercial demand.

Phase 0 tests only whether this service package can be specified coherently and
safely. It does not show that AEG improves repair outcomes or that customers
want the service.
