# Keep the handoff explicit

Select **Copy capsule** only after inspecting the evidence.

Then open VS Code Chat from the Chat menu, paste the capsule into the chat input with the original task, and press Enter. On macOS, use Control+Command+I; on Windows or Linux, use Ctrl+Alt+I.

AEG copies the text. It does not open an undocumented chat surface, send the prompt, or run the agent.
