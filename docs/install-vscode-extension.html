What is included

A focused developer preview.

AEG surfaces evidence and limitations. The extension does not promise that a retrieved experience will improve a repair.

Verified-only lookup

Searches the validated public library; candidate and malformed records are excluded.

Explainable matching

Shows the overlapping query terms and the record fields contributing to rank.

Guarded capsules

Packages lessons, constraints, failure warnings, and a requirement to verify locally.

Local ratings

Stores usefulness feedback in .aeg/verified-experience-feedback.json.

Playwright diagnosis

Captures local failure and recovery receipts with explicit outcome verification.

Public repair lab

Runs bounded local baseline/assisted comparisons; it never pushes upstream.

Build from source

Audit the package yourself.

Clone

git clone https://github.com/yao23/agent-experience-graph.git
cd agent-experience-graph/integrations/vscode

Install, test, and package

npm ci
npm test
npm run package

Install the VSIX

code --install-extension agent-experience-graph-0.1.5.vsix

Privacy boundary

Local by default.

Version 0.1.5 does not upload code, task descriptions, capsules, logs, artifacts, ratings, or experience receipts. Review .aeg/ before committing it.

Evidence boundary

The bundled challenge demonstrates discoverability, verified-only retrieval, provenance, explainability, guardrails, and local feedback. Its prior comparison did not improve the outcome and increased token usage and wall time.
