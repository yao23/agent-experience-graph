Experience infrastructure for AI agents.

AI models learn from data. AI agents should be able to retrieve verified experience. AEG v0.1.3 tests whether compact debugging lessons, failed approaches, constraints, and provenance can improve a coding agent's starting context.

The problem

AI agents forget what worked.

Agents can reason, retrieve documents, and use tools—but they rarely accumulate reusable execution experience. Teams pay repeatedly for the same discovery, failures, and recovery work.

01

Repeated work

Similar tasks are decomposed and solved from scratch across sessions, agents, and teams.

02

Lost lessons

Failure modes, tool choices, recovery paths, latency, and cost are rarely preserved as reusable knowledge.

03

Brittle systems

Without outcome-driven experience, agent quality depends too heavily on prompts and one-off context.

Why now

The agent stack is maturing. One layer is still missing.

View schema

Current evidence is intentionally narrow. The public library has two verified records; existing controlled transfer pairs did not improve correctness and do not establish cross-project or generalized benefit. The immediate goal is 5–10 seed users reporting real helpful, neutral, irrelevant, and harmful outcomes.
