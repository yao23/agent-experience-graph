# 02 — API/dependency migration

## Operating contract

- **Project category:** bounded migration from one deprecated API, dependency contract, runtime, or action version.
- **Independent external value:** keep a small public project compiling and tested on a supported dependency/runtime.
- **AEG consumption/production:** retrieve migration/runtime compatibility experience; produce a versioned compatibility record with exact before/after commands.
- **Selection criteria:** permissive license; active small project; deprecation or break is public and reproducible; lockfile or pinned version exists; focused compile/tests; ≤3 source/config files.
- **Exclusions/safety:** framework rewrites, mass dependency updates, autogenerated PR campaigns, unbounded lockfile churn, secrets/services, security upgrades needing disclosure, unclear license.
- **Bounded pilot:** one dependency/API edge; at most five candidates and three scored; 45 minutes/25 commands.

## Procedure

1. **Freeze:** pin repository commit, old/new API or dependency versions, public provenance, compile/test commands, expected failure, success oracle, scope, contribution policy; hash manifest.
2. **Retrieve:** query verified library for dependency/API/runtime phrases and subtasks; record complete ranking, evidence, threshold, capsule size, and abstention/recommendation.
3. **Execute:** clone under `/tmp`; establish before result; change the minimal call/config plus focused test only; avoid unrelated formatter or lockfile updates.
4. **Verify:** compile/typecheck before/after, focused test, related suite, documented build/lint, diff/lockfile audit.
5. **Record:** versions, failure signature, attempts/recovery, commands, verification, metrics, hashes, files, retrieval effect, reusable migration rule and limitations.

## Outcomes and metrics

- **Success:** deprecated/broken edge reproduced and migrated with relevant checks green.
- **Partial:** migration compiles or focused test passes but broader compatibility remains unverified.
- **Blocked:** target needs credentials/services, current versions no longer reproduce, or scope is broad.
- **Failure:** migrated path remains broken or introduces a regression.
- **Metrics:** candidates/scores, dependency delta, commands/tests, elapsed time, tokens/cost or `null`, patch size, retrieval score/capsule.
- **Stopping conditions:** dependency solver expands beyond bounded edge, generated changes dominate, 25 commands/45 minutes, license/safety concern.
- **External approval later:** push/PR/comment, publish package, trigger CI, change dependabot/renovate configuration upstream, promote experience.

## Next-pilot recommendation template

`Old→new contract / target / proof of deprecation / oracle / scope estimate / follow-up risk / approval needed.`
